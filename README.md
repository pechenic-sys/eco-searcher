# eco-searcher
Навык для поиска в Интернете через Serper и анализа источников с DeepSeek. Поддерживает фразу «Найди в Интернет», дедупликацию URL, извлечение текста страниц, структурированные evidence-пакеты, настройку API-ключей, безопасную установку и контроль расходов токенов. Экономия до 85% токенов
