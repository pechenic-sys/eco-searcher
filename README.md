# eco-searcher

## Serper + DeepSeek Search Skill

Codex-навык для фразы «Найди в Интернет»: Serper получает актуальные результаты Google, помощник очищает и сокращает публичные страницы, а DeepSeek превращает их в компактный evidence packet с цитатами, ссылками и ограничениями.

## Возможности

- автоматическое срабатывание на русские и английские варианты веб-поиска;
- Serper API с настройками языка, страны, количества результатов и повторов;
- дедупликация URL и опциональное чтение публичных HTML-страниц;
- структурированный JSON вместо длинного пересказа;
- явное разделение найденного факта, цитаты, уверенности и пробела в данных;
- конфиг-файл без публикации секретов и установщики для Windows/Linux/macOS.

## Быстрый старт

```text
git clone <URL-репозитория>
cd serp-deepseek-search
python scripts/install.py
copy config.example.toml config.toml
```

Заполните два ключа по [руководству пользователя](docs/USER_GUIDE.md), затем используйте в Codex: «Найди в Интернет …».

## Безопасность

Ключи не зашиты в код, `config.toml` игнорируется Git, а ошибки не печатают секреты. Перед публикацией проверьте `git diff` и историю коммитов. См. [SECURITY.md](SECURITY.md).
