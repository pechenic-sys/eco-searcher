# Руководство пользователя

## Установка

Скачайте репозиторий и запустите `install.ps1` в PowerShell или `install.sh` в Linux/macOS. Вручную это эквивалентно:

```text
python scripts/install.py
```

После установки новый Codex сможет автоматически выбрать навык по фразе «Найди в Интернет» и похожим формулировкам. Для явного запуска используйте `$serp-deepseek-search`.

## Ключи

1. Зарегистрируйтесь на [Serper](https://serper.dev/), откройте личный кабинет и создайте API key. Документация использует endpoint `https://google.serper.dev/search` и заголовок `X-API-KEY`.
2. Создайте API key на [DeepSeek API Platform](https://platform.deepseek.com/api_keys). Официальный API использует `https://api.deepseek.com/chat/completions` и Bearer-заголовок.
3. Скопируйте `config.example.toml` в `config.toml` рядом с установленным `SKILL.md` и заполните `serper_api_key` и `deepseek_api_key`.

Вместо файла можно задать `SERPER_API_KEY` и `DEEPSEEK_API_KEY`. Переменные окружения имеют приоритет. Не вставляйте ключи в сообщения Codex, GitHub, README или скриншоты.

## Использование

Попросите: «Найди в Интернет официальные данные о …, укажи ссылки и отдели факты от предположений». Для запуска помощника из терминала:

```text
python scripts/search_web.py "официальные данные о ..." --config config.toml --fetch-pages
```

Без `--fetch-pages` анализируются SERP-заголовки и сниппеты; с флагом помощник пытается прочитать публичные HTML-страницы. Закрытые, платные и требующие входа страницы не обходятся.

## Что возвращается

Сначала формируется evidence packet: найденные URL, выдержки, утверждения, уровень уверенности и ограничения. Итоговый ответ должен ссылаться на источники; JSON от модели не является самостоятельным доказательством.

## Лимиты и расходы

Serper и DeepSeek тарифицируются по правилам их аккаунтов. Уменьшайте `results_per_query`, `max_sources` и `max_page_chars`, если нужен дешёвый быстрый поиск. Не отправляйте в модель большие повторяющиеся архивы.
